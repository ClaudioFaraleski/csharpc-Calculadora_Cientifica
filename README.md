# Calculadora Científica

Uma calculadora científica desenvolvida em C# Windows Forms com funcionalidades avançadas.

## 🔍 Funcionalidades

### Operações Básicas
- ➕ Adição
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão

### Operações Avançadas
- √ Raiz Quadrada
- x² Exponenciação
- % Porcentagem
- ±️ Inversão de Sinal
- 1/x Inverso
- π Constante PI
- e Número de Euler

### Recursos
- 📟 Display de alta precisão
- 🔄 Limpar entrada (CE)
- 🧮 Cálculos encadeados
- ⚠️ Tratamento de erros
- 🎨 Interface intuitiva

## 🚀 Tecnologias Utilizadas
- C# .NET 6.0
- Windows Forms
- Visual Studio 2022

## 📋 Pré-requisitos
- .NET 6.0 SDK ou superior
- Windows 7 ou superior

## ⚙️ Como Executar
1. Clone o repositório
2. Abra a solução no Visual Studio
3. Pressione F5 para executar
